# Спецификации вариантов использования (Use Cases) FinHall

## Описание актеров (Действующих лиц)

*   **Клиент (Client)** — физическое лицо, пользователь банковских услуг. Инициирует вход в систему, просмотр баланса, переводы и экспорт выписок.
*   **Администратор (Admin)** — сотрудник банка. Отвечает за настройку глобальных лимитов и управление учетными записями.
*   **Платёжный шлюз (Payment Gateway)** — внешняя система, обрабатывающая транзакции. Участвует в процессе перевода средств.
*   **Сервис курсов валют (Currency API)** — внешняя система (например, API НБРБ), предоставляющая актуальные курсы валют.

## UC-01: Вход в систему (Authentication with 2FA)

*   **Краткое описание:** Пользователь входит в систему, используя логин, пароль и одноразовый код, который приходит на почту.
*   **Актеры:** Клиент, Администратор.
*   **Предусловия:** Пользователь зарегистрирован в системе.
*   **Основной поток:**
    1. Пользователь вводит логин и пароль на экране входа.
    2. Система проверяет корректность пароля.
    3. Система генерирует 2FA-код и отправляет его на email пользователя.
    4. Пользователь вводит код из email.
    5. Система подтверждает код и выдает JWT-токен.
    6. Пользователь попадает на главный экран (Dashboard).
*   **Альтернативный поток (A1): Неверный пароль.**
    1. На шаге 2 система определяет, что пароль неверный.
    2. Система выводит сообщение об ошибке.
    3. Возврат к шагу 1 (пользователь может попробовать снова).
*   **Альтернативный поток (A2): Неверный 2FA-код.**
    1. На шаге 5 система определяет, что код не совпадает или истек.
    2. Система выводит сообщение об ошибке и предлагает запросить новый код.
    3. Возврат к шагу 3.
*   **Постусловия:** Пользователь аутентифицирован, получен JWT-токен, открыт доступ к функциям системы.

## UC-02: Перевод средств (Funds Transfer)

*   **Краткое описание:** Клиент переводит деньги между своими счетами или на счет другого клиента.
*   **Актеры:** Клиент, Платёжный шлюз.
*   **Предусловия:** Пользователь авторизован. У него есть хотя бы один счет с достаточным балансом.
*   **Основной поток:**
    1. Клиент выбирает счет списания и счет зачисления.
    2. Клиент вводит сумму перевода.
    3. Система проверяет, не превышает ли сумма дневной лимит.
    4. Система проверяет наличие достаточной суммы на счете списания.
    5. Система обращается к Платёжному шлюзу для проведения транзакции.
    6. Платёжный шлюз подтверждает успех.
    7. Система обновляет балансы счетов и сохраняет транзакцию в БД.
    8. Система выводит сообщение об успешном переводе.
*   **Альтернативный поток (A1): Недостаточно средств.**
    1. На шаге 4 система обнаруживает нехватку средств.
    2. Система выводит сообщение: «Недостаточно средств на счете».
    3. Вариант использования завершается.
*   **Альтернативный поток (A2): Ошибка Платёжного шлюза.**
    1. На шаге 6 шлюз возвращает ошибку (например, таймаут).
    2. Система откатывает транзакцию (rollback).
    3. Система выводит сообщение об ошибке: «Не удалось провести платеж. Попробуйте позже».
*   **Постусловия:** Средства переведены, транзакция записана в историю с соответствующим статусом, балансы обновлены.

## UC-03: Экспорт выписки в PDF (Export Statement to PDF)

*   **Краткое описание:** Клиент выгружает историю своих транзакций за выбранный период в виде PDF-файла.
*   **Актеры:** Клиент.
*   **Предусловия:** Пользователь авторизован. В системе есть хотя бы одна транзакция за выбранный период.
*   **Основной поток:**
    1. Клиент открывает раздел «История транзакций».
    2. Клиент нажимает кнопку «Экспорт в PDF» и выбирает период.
    3. Система запрашивает данные из БД.
    4. Система с помощью библиотеки iText формирует PDF-документ с таблицей транзакций.
    5. Система отправляет файл клиенту.
    6. Браузер клиента скачивает файл.
*   **Альтернативный поток (A1): Нет транзакций за период.**
    1. На шаге 3 система не находит транзакций.
    2. Система выводит сообщение: «За выбранный период операций не найдено».
    3. Вариант использования завершается.
*   **Постусловия:** PDF-файл с выпиской сформирован и скачан на устройство пользователя.
