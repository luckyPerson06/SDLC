# Глоссарий проекта FinHall

| Термин / Сокращение | Определение |
| :--- | :--- |
| **FinHall** | Название разрабатываемого веб-приложения для интернет-банкинга. |
| **Клиент** | Физическое лицо, пользователь банковских услуг (основной актер системы). |
| **Администратор** | Сотрудник банка, управляющий лимитами и учетными записями клиентов. |
| **SPA** | Single Page Application — одностраничное веб-приложение, загружающее контент без перезагрузки страницы. |
| **API** | Application Programming Interface — программный интерфейс для взаимодействия между компонентами системы. |
| **2FA** | Two-Factor Authentication — двухфакторная аутентификация (вход по паролю и одноразовому коду на email). |
| **JWT** | JSON Web Token — стандарт токенов доступа, используемый для безопасной аутентификации пользователей. |
| **Dashboard** | Главный экран (панель управления) приложения, отображающий баланс и основные виджеты. |
| **Транзакция** | Операция перевода денежных средств между счетами. |
| **Выписка** | Документ с историей транзакций клиента за выбранный период (экспортируется в PDF). |
| **Лимит на одну операцию** | Максимальная сумма, которую можно перевести за одну транзакцию. |
| **Суточный лимит** | Максимальная суммарная сумма переводов, которую клиент может совершить за один день. |
| **Rollback** | Откат транзакции к предыдущему состоянию при возникновении ошибки (обеспечивает целостность данных). |
| **BR** | Business Requirement — бизнес-требование. |
| **MVP** | Minimum Viable Product — минимально жизнеспособный продукт (версия с минимальным набором функций). |
| **REQ** | Requirement — идентификатор требования (например, REQ-FUNC-001). |
| **Внешняя система** | Сторонний сервис (например, API курсов валют), который не является частью FinHall, но с которым система взаимодействует. |
