# Глоссарий проекта FinHall

| Термин / Сокращение | Определение |
| :--- | :--- |
| **FinHall** | Название разрабатываемого веб-приложения для интернет-банкинга (SPA с REST API). |
| **SPA** | Single Page Application — одностраничное приложение, загружающее контент без перезагрузки страницы (Frontend на React). |
| **Backend** | Серверная часть приложения, реализованная на Java Spring Boot. |
| **Frontend** | Клиентская часть приложения, реализованная на React. |
| **API** | Application Programming Interface — программный интерфейс для взаимодействия Frontend и Backend по протоколу REST (JSON). |
| **JWT** | JSON Web Token — стандарт токенов доступа для stateless-аутентификации. |
| **2FA** | Two-Factor Authentication — двухфакторная аутентификация (пароль + код на email). |
| **ACID** | Атомарность, Согласованность, Изолированность, Долговечность — требования к транзакционной системе (PostgreSQL). |
| **Dashboard** | Главный экран (панель управления) приложения, отображающий баланс и виджеты. |
| **Транзакция** | Операция перевода денежных средств между счетами. |
| **Выписка (Statement)** | Документ с историей транзакций клиента за период (в FinHall экспортируется в PDF). |
| **Лимит (Limit)** | Ограничение на сумму/количество операций (дневной лимит, лимит на одну операцию). |
| **iText** | Java-библиотека для генерации PDF-документов. |
| **BR** | Business Requirement — бизнес-требование. |
| **MVP** | Minimum Viable Product — минимально жизнеспособный продукт. |
| **PCI DSS** | Стандарт безопасности данных индустрии платёжных карт (базовое соответствие). |
| **Rollback** | Откат транзакции к предыдущему состоянию при ошибке (обеспечивает ACID). |
| **Mock (Мок)** | Эмуляция внешнего сервиса (в FinHall — для платёжного шлюза) для тестирования без реальных денег. |
| **REQ** | Requirement — идентификатор требования (например, REQ-FUNC-001). |
